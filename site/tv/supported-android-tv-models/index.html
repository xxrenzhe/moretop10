Unofficial guide. This cluster discusses a third-party open-source project called CleanYourTV. MoreTop10 is not affiliated with that project, its authors, any TV brand, or any domain that uses that name. We do not host the software. Checkout and returns stay with the retailer.

As of 2026-10-22, this table is a scaffold. The unofficial CleanYourTV repository documents supported builds under examples/; that list moves. We will not hard-code “54,” “23,” or “66” models as if they were a permanent count. If your set is missing, go to when software will not install rather than assuming a checkout link.

How to read this table

Retail stickers say “Hisense U8” or “Toshiba Fire TV.” The software path cares about the Android / Google TV build and whether USB debugging stays on. Fire TV panels are listed only so you do not confuse them with Google TV. Samsung and LG do not belong here.
