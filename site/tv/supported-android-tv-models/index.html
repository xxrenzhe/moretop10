How to read this table

Retail stickers and software builds disagree. Match the OEM and the model / board string, then the platform. Try software first means Android TV / Google TV with a documented debloat list — see Google TV ads. Debloat only means Fire OS or a firmware that will not hand Home to a third-party launcher — not a reason to buy Fire hardware; read Fire TV panels. Samsung Tizen and LG webOS are not in this table: there is no supported ADB path. Use Samsung ads or LG ads, then the decision tree if you are replacing the set.
