As of 2026-10-22, the unofficial CleanYourTV launcher is the project this cluster documents for Android TV / Google TV ad rows — third-party open-source, non-official, and not hosted here. We are not selling a launcher. There is no Check price button and no ASIN. Rank on fit: does it stay default, hide boot and home-row promos, and keep HDMI-CEC? Then follow the install guide. If ADB fails, use ADB troubleshooting before you shop. A Fire Stick is not a launcher and we will not recommend one.

What a launcher can and cannot do

A replacement home app can hide boot splashes, promoted rows, and some “because you watched” shelves on Android TV / Google TV. It cannot remove ads inside Netflix or YouTube. It cannot add ADB to Samsung Tizen, LG webOS, or Apple tvOS. It cannot make a Fire TV into Google TV. If the frustration is “this OS phones home,” that is a privacy or non-smart decision, not a new APK.

  • Can: become the default Home, skip some boot promos, and give you a quieter row of inputs and apps you chose.
  • Cannot: unsubscribe you from an ad-tier streaming plan, disable every vendor telemetry toggle, or survive a firmware that locks Developer options.

How we rank (validation, not scores)

We do not publish star scores or a Top 10 of launchers. A number would pretend we lab-tested every build. These checks are the rank, in order:

  1. Does it stay default after a reboot and after a power-cycle from the wall? If Home snaps back to the stock row, the install is not done.
  2. Does it hide boot and home-row promos without breaking HDMI-CEC, live inputs, or the power-off picture?
  3. Is the install path documented for your build on the unofficial project’s README — not a year-old screenshot?
  4. Can you reach Settings and inputs without a second remote app?
  5. Does a vendor overlay (Hisense, TCL, Sony skins) fight it on every boot?

After you install — validate

  1. Reboot twice. Confirm Home is still the community launcher, not a one-shot override.
  2. Cold-boot from the wall. Some overlays only lose the fight until the next mains cycle.
  3. Open HDMI-1 and CEC volume. If those broke, the quieter row is not a win.
  4. Check boot ads and the first three home rows. App-inside ads will still be there.
  5. If Home resets, Developer options vanished, or ADB cannot see the TV, stop here and open ADB not working.

When to leave this page

  • You have not installed anything yet — start on how to remove smart TV ads.
  • ADB cannot connect, debugging wipes, or the launcher will not stay default — troubleshooting.
  • The set is Tizen, webOS, or tvOS, or you are replacing the panel — when software will not install.
  • You want the OS gone, or you want fewer accounts and no ACR — non-smart TVs or TVs for privacy.
  • You are not sure which page you need — the hub.
